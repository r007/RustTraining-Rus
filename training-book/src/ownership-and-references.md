## Упражнение 2.2.1: Семантика перемещения

*Упражнение адаптировано из [упражнения на семантику перемещения](https://github.com/rust-lang/rustlings/tree/main/exercises/06_move_semantics) проекта Rustlings.*

Находясь в папке `exercises/2-foundations-of-rust/2-ownership-and-references/1-move-semantics`, чтобы начать, выполните:
```bash
cargo run --bin 01
```

Эта команда попытается скомпилировать упражнение 1. Добейтесь, чтобы пример запустился, и переходите к следующему упражнению, заменив номер в команде `cargo run`.

Некоторые упражнения содержат модульные тесты. Чтобы запустить тест из `src/bin/01.rs`, выполните
```bash
cargo test --bin 01
```
Убедитесь, что все тесты проходят!

`01.rs` должен компилироваться без изменений, но остальные примеры тоже нужно заставить компилироваться. В некоторых упражнениях инструкции записаны в виде doc-комментариев в начале файла. Обязательно следуйте им.

## Упражнение 2.2.2: Заимствование

Обязательно следуйте инструкциям в комментариях!
