## Упражнение 2.1.1: Базовый синтаксис

Откройте `exercises/2-foundations-of-rust/1-basic-syntax/1-basic-syntax` в редакторе. В этой папке собраны упражнения, с помощью которых можно потренировать базовый синтаксис Rust.

Чтобы начать, находясь в папке `exercises/2-foundations-of-rust/1-basic-syntax/1-basic-syntax`, выполните:
```bash
cargo run --bin 01
```

Эта команда попытается скомпилировать упражнение 1. Добейтесь, чтобы пример запустился, и переходите к следующему упражнению, заменив номер в команде `cargo run`.

Некоторые упражнения содержат модульные тесты. Чтобы запустить тесты из `src/bin/01.rs`, выполните
```bash
cargo test --bin 01
```
Убедитесь, что все тесты проходят!
