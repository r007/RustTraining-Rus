В этом упражнении вы будете работать с динамической диспетчеризацией: десериализовать файл с помощью `serde_json` или `serde_yaml` в зависимости от его расширения. Стартовый код находится в `exercises/2-foundations-of-rust/5-closures-and-dynamic-dispatch/1-config-reader`. Исправьте все места, помеченные `todo`.

Чтобы запустить программу, нужно передать файл для десериализации самому бинарнику, а не Cargo. Для этого выполните
```bash
cargo run -- <FILE_PATH>
```

Успешная десериализация и `config.json`, и `config.yml` должна корректно выводить `Config`.
